# Science Experience Blueprint

## Purpose
To explore the natural world and scientific phenomena through the lens of Islamic epistemology, demonstrating harmony between revelation and empirical observation.

## Primary User Intentions
- Read articles on cosmology, embryology, geology, or biology as referenced in the Quran.
- Understand the historical context of Islamic Golden Age scientific discoveries.

## First-Screen Experience
- **Visual Grid**: Stunning imagery representing various scientific disciplines (Space, Earth, Biology, Mathematics).
- **Featured Node**: A spotlight on a specific phenomenon (e.g., "The Expanding Universe").

## Navigation Hierarchy
- **Level 1**: Science Home (Disciplines Grid)
- **Level 2**: Articles/Observations List
- **Level 3**: Scientific Node (Universal Reader)

## Reading / Task Flow
1. User selects a scientific discipline.
2. The user reads a highly structured article that pairs empirical data with primary revelation.

## Universal Knowledge Component Usage
- **MetadataDisplay**: Clearly delineates the `AuthorityClass` (e.g., distinguishing between a established *scientific_observation* and a theological *primary_revelation*).
- **RelatedKnowledge**: Used to link scientific articles directly to the specific Quranic Ayahs they discuss.

## Reader Integration
Heavy use of the `KnowledgeMedia` component for diagrams, infographics, and high-quality photography.

## Search Integration
Indexed by scientific terms (e.g., "Embryo", "Orbit").

## Library Integration
Articles can be bookmarked or added to study collections.

## Accessibility Considerations
- Complex infographics must be accompanied by detailed descriptive text in the article body.

## Desktop vs Mobile Behavior
- **Desktop**: Wide layouts allow for side-by-side text and imagery.
- **Mobile**: Linear stacking; imagery always precedes the explanatory text block.

## Progressive Disclosure Strategy
- Deep technical scientific data or formulas are relegated to expandable sections or the `KnowledgePanel`, keeping the primary text accessible to laypeople.

## Future Roadmap (v2/v3)
- **v2**: Interactive 3D models (e.g., solar system orbits as described by classical scholars).
- **v3**: Integration with modern scientific databases for live data overlays.
