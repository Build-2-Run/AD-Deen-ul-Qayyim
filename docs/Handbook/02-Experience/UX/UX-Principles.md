# UX Principles

The User Experience of AD-Deen-ul-Qayyim (ADQ) is governed by a singular, overarching philosophy: **Calm Focus**. The interface must never distract users from their current task. It must serve the knowledge, not overshadow it.

## Core Tenets

1. **Calmness over Clutter**
   - Interfaces should breathe. Use generous spacing (macro and micro) to reduce cognitive load.
   - Avoid aggressive colors, flashing elements, or high-anxiety patterns (like artificial urgency).

2. **Focus Management**
   - The user should only see what they need to accomplish their immediate goal.
   - Employ progressive disclosure: hide secondary actions in menus or contextual panels until requested.
   - Feature a dedicated "Reading Focus" mode that strips away navigation and chrome.

3. **Respectful Interactions**
   - Treat the content (Quran, Hadith, Fiqh) with the utmost reverence.
   - Typography must be legible, beautiful, and traditionally sound, especially for Arabic script.
   - Do not use colloquialisms or informal language in system feedback. Maintain a dignified tone.

4. **Clarity and Elegance**
   - Form follows function, but the form must be premium. 
   - Use the established Design System tokens (elevation, radius, color) to create a cohesive, timeless aesthetic.
   - Navigation should be entirely predictable.

5. **Universal Paradigms**
   - Establish patterns once and reuse them everywhere. (e.g., the `KnowledgePanel` should behave identically whether triggered from a Quran Ayah or a History article).
